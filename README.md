# SQL-project
Data Cleaning e Gestione Database: Ho effettuato la pulizia e la normalizzazione di un database logistico utilizzando SQL, risolvendo duplicati anagrafici in diverse tabelle tramite l'utilizzo di CTE (Common Table Expressions) e query di UPDATE per ripristinare la corretta integrità referenziale.

Analisi delle Performance Logistiche: Ho incrociato i dati sullo stato delle spedizioni con le modalità di trasporto (Air, Road, Sea), estraendo insight chiave come il maggior tasso di ritardo per le spedizioni via mare (16,5%) e il più alto tasso di cancellazione per quelle su strada (18,9%).  

Data Quality e Definizione di KPI: Ho individuato e gestito anomalie critiche nei dataset (es. 297 spedizioni su 420 con modalità di trasporto non coincidenti, pesi negativi e costi estremi) e ho stabilito il tasso di puntualità delle consegne come metrica primaria per il monitoraggio settimanale delle performance.
